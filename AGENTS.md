# Publicação e execução local

- Esta cópia usa identidade visual neutra e somente dados fictícios.
- Nunca adicionar credenciais reais, arquivos de ambiente, backups ou dados de clientes ao Git.
- Não importar o histórico Git dos projetos originais.
- Não fazer push nem alterar visibilidade no GitHub sem comando explícito do proprietário.
- A revisão local do proprietário deve ocorrer antes da primeira publicação.
- Manter bancos e serviços locais isolados; não apontar para produção ou homologação.
